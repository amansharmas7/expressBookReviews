# Contributing

This is an educational Express starter. Keep changes aligned with the documented project scope and do not describe unfinished route handlers as production-ready.

Before opening a pull request:

1. Explain the change and its intended behaviour.
2. Add or update Node.js tests for new functionality.
3. Run `npm run check` and `npm test` from `final_project/`.
4. Update the repository README if route status or setup changes.
5. Do not commit `.env`, session secrets, user credentials, or real customer data.
