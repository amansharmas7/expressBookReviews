# Express Book Reviews — Application

This directory contains the Node.js/Express application for the educational starter project.

For prerequisites, environment setup, API route status, tests, and security limitations, use the [repository-level README](../README.md).

Run from this directory:

```bash
npm install
npm start
```

Set a unique `SESSION_SECRET` in `.env` before starting the server. The current registration, login, and book/review route handlers are intentionally unfinished and return HTTP 501. Do not use this starter with real customer accounts or data.
