# Security Policy

## Supported versions

Security fixes are considered for the latest revision on `main`.

## Reporting

Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository, when available. Do not include passwords, tokens, session secrets, or personal data.

## Current project limitations

This is an unfinished educational starter. Registration, login, JWT validation, authorization, persistence, and multiple route handlers are not fully implemented. The Express session configuration uses the default in-memory store. Do not deploy it as a production service or use it with real customer credentials or personal data.
